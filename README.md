# 🚁 AeroEngine Digital Twin Dashboard

SIH 2026 PS-8 Project
AI-Enabled Real-Time Digital Twin System for Health Monitoring,
Fault Prediction & Mission Reliability Enhancement of Aero Piston Engines
used in MALE UAVs.

## Features
- Real-time engine health monitoring
- Physics-based Digital Twin with residual analysis
- Anomaly Detection (Isolation Forest)
- Fault Diagnosis with Explainable AI (XAI)
- RUL Estimation
- Pilot, Engineer & Maintenance Views
